# BNF — Random `if`-Condition Generator

[![C](https://img.shields.io/badge/C-99-A8B9CC.svg)](https://en.wikipedia.org/wiki/C_(programming_language))
[![Make](https://img.shields.io/badge/Build-Make-427819.svg)](https://www.gnu.org/software/make/)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

A C program that generates random `if`-statement conditions from a small **Backus–Naur Form** grammar. Each run picks productions at random until every non-terminal resolves to a terminal pulled from token files on disk. Built as an assignment for **Hacettepe University — BBM203 Software Lab**.

## Grammar

```
<cond>   ::= <cond> <set_op> <cond>
           | <expr> <rel_op> <expr>

<expr>   ::= <expr> <op>  <expr>
           | <pre_op> <expr>
           | <var>
```

Each terminal (`set_op`, `rel_op`, `op`, `pre_op`, `var`) is read as a random line from the corresponding token file.

## How It Works

The program maintains **two data structures simultaneously** over the same nodes:

1. **Binary tree** — built by `insertion()`; encodes the parse-tree structure of the generated expression.
2. **Linked list** — built by `append()`; preserves the left-to-right token order for printing.

For each production, a uniform random integer chooses which rule to expand. Recursion bottoms out at a `<var>` terminal. The final output is generated by `printPreorder()` and wrapped in `if (` … `)){}` for valid C-like syntax.

## Input Files (required at runtime)

The program reads the following files **from the current working directory** — each one a list of terminals, one per line:

| File | Example terminals |
|------|-------------------|
| `op`     | `+`, `-`, `*`, `/` |
| `pre_op` | `-`, `!`, `~` |
| `rel_op` | `<`, `>`, `==`, `!=`, `<=`, `>=` |
| `set_op` | `&&`, `\|\|` |
| `var`    | `x`, `y`, `count`, `flag` |

> These files are **not bundled** in the repo. Create them yourself before running the program.

## Build

```bash
make
```

Or compile directly:

```bash
gcc -o bnf bnf.c
```

## Run

```bash
# Make sure op, pre_op, rel_op, set_op, var files exist in the current directory
./bnf
```

## Example Output

```
if ((x + y) > (count - 1)){}
if (((!flag) && (x == 0))){}
if ((((x * 2) + y) >= count)){}
```

Each invocation produces a different result because the RNG is seeded with `time(0)` and recursive depth is bounded by random choices.
